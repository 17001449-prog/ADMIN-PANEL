# ADMIN PANEL — улучшенная версия

Готовые скрипты для Roblox Studio:

| Файл | Куда вставить |
|---|---|
| `ADMIN SERVER.txt` | `Script` в `ServerScriptService` |
| `ADMIN CLIENT.txt` | `LocalScript` в `StarterPlayer > StarterPlayerScripts` |

Скопируйте содержимое файлов в соответствующие скрипты. Имена файлов в Studio могут быть любыми.

---

## 🔨 Что нового в банах

* **Срок бана в любых единицах:** секунды, минуты, часы, дни, недели, месяцы, годы или навсегда.
* **Бан по нику или по ID** — ник преобразуется в UserId на сервере автоматически.
* **Список забаненных** с ником, причиной, оставшимся временем, датой окончания и админом, который выдал бан.
* **Изменение срока** уже выданного бана (кнопка `EDIT TIME`) без удаления и повторного бана.
* **Разбан** отдельной кнопкой в списке и в панели.
* **Мгновенный кик** игрока при бане с указанием срока и причины.
* **Защита от ошибок:** нельзя забанить себя, владельца или пользователя с равными/большими правами.
* **Автоочистка истёкших банов** раз в 15 минут + проверка при входе игрока.
* **Совместимость:** старые баны из `AdminBans_v1` продолжают работать.

Формат длительности, который понимает сервер:

```lua
{ value = 3, unit = "d" }   -- 3 дня
{ value = 2, unit = "w" }   -- 2 недели
{ value = 30, unit = "s" }  -- 30 секунд
0                            -- навсегда
```

Поддерживаемые `unit`: `s/sec`, `m/min`, `h/hr`, `d/day`, `w/week`, `mo/month`, `y/year`.

## 🎛 Новые вкладки и возможности

### PLAYERS (модератор)
Список игроков + сетка действий:

* `HINT`, `MESSAGE` — сообщение всем (с длительностью)
* `KICK`, `KILL`
* `FREEZE` / `UNFREEZE`
* `BRING` — телепорт выбранного к себе
* `TP TO` — телепорт к выбранному
* `GOD` / `UNGOD`
* `RESPAWN`, `NUKE`
* `SPEED`, `JUMP`
* `SIT` / `UNSIT`

### SERVER (владелец)
* Информация: Job ID, Place ID, онлайн, аптайм, память, статус блокировки.
* `ANNOUNCE ALL` — красивое объявление всем игрокам.
* `LOCK SERVER` / `UNLOCK` — закрыть сервер для обычных игроков (моды остаются).
* `RESTART SERVER` — перезапустить сервер.
* `UNBAN ALL` — снять все баны (с подтверждением).
* `SHUTDOWN SERVER` — выключить сервер (с подтверждением).

### LOGS
* Фильтр по типу действия (`BAN`, `UNBAN`, `KICK`, `TELEPORT` и т.д.).
* Поиск по тексту лога.
* Удаление записи.

### BAN
* Быстрые пресеты срока: `1H`, `6H`, `1D`, `3D`, `7D`, `30D`, `PERM`.
* Готовые причины: читы, абуз, спам, оскорбления и т.д.
* Редактирование срока бана.

## ⚙️ Настройки

В начале `ADMIN SERVER.txt` и `ADMIN CLIENT.txt`:

```lua
local GROUP_ID  = 377918102
local MIN_RANK  = 3      -- доступ к панели
local MOD_RANK  = 254    -- модератор
local BAN_RANK  = 255    -- владелец

local OWNER_ID_1 = 1447349304
local OWNER_ID_2 = 11955295268
local FRIEND_ID  = 2227149740
```

* В **Studio** права выдаются автоматически (rank 255) — удобно тестировать.
* Для работы банов в опубликованной игре включите **API Services** в настройках места (Game Settings → Security → Enable Studio Access to API Services для теста, и Publications → API Access для продакшена).
